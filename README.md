# Prophets

## Description
Prophets is an iOS application that presents a list of prophets and allows users to view detailed information about each prophet. The app is built using SwiftUI, SwiftData for storage, and Kingfisher for image caching and retrieval.

## Installation

### Prerequisites
- Xcode 15
- iOS 17 or later

### Steps
1. Fork this repository on GitHub to your own account.
2. Clone your fork:
   ```sh
   git clone https://github.com/<your-github-username>/Prophets.git
   ```
3. Open the project in Xcode.
4. Build and run the app on a simulator or physical device (minimum iOS version of 17).

## Usage
- Launch the app to view a list of prophets.
- Tap on a prophet to view detailed information.

## Features
- Modern UI with SwiftUI
- Navigation between main and detail screens
- Local data storage with SwiftData
- Caching of images with Kingfisher
